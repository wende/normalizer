# Golden-output validation

This harness compares the rewrite's current CLI output against PNGs generated
by upstream Laigter.

```sh
make fixtures
make regenerate-goldens UPSTREAM_LAIGTER=/path/to/upstream/laigter
make golden
```

On macOS with `qmake` available, the local upstream binary can be built and
used in one step:

```sh
make regenerate-goldens-local
```

`make golden` builds `build/laigter-core-cli`, regenerates current outputs into
`tests/golden/current/`, and compares them against `tests/golden/upstream/`.
The upstream PNGs are intentionally generated by a separate target so changes
to the expected output are explicit.

The first manifest only covers default normal-map generation, because that is
the implemented MVP surface. Add parallax, specular, occlusion, parameter
sweeps, overlays, tileability, and sprite sheets to `manifest.json` as those
features land.
